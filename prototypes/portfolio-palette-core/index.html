03 / How the shades are made

Shift perceptual lightness, not an RGB brightness slider.

The five core hues follow the relationships in your original block. Their lightness is intentionally uneven: citron is the light spike and indigo is the low note. That variation helps the five-color block avoid a flat middle row.

Each lighter or darker sample starts with its core OKLCH coordinates. A recorded lightness change sets the tone, a chroma change controls intensity and a small hue shift preserves the original green to teal and pink to red movement. Colors outside standard RGB are brought into range by reducing chroma while holding lightness and hue.

The core values remain the five primary colors. The samples below are generated options, not ten additional colors that must all appear on the site.

04 / Recommendation

Start with the five-color block.

The new core block is the actual palette test. The paired version demonstrates how that palette can grow without choosing a second set of unrelated colors. The brighter pair samples should only be used where the page needs that extra contrast.

This is a proposal, not a final color decision. The palette values and shade recipe are available to copy into Figma.
