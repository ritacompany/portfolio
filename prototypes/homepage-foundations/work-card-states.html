Work card states

A hiring manager reaches these cards asking one thing: which one do I open? The states only have to say "this opens" and get out of the way of the work. Hover the cards or tab to them.

  • Whole card is the link. Image, title and description are one target, so the click lands wherever the eye is (Fitts's law). One tab stop per card.
  • Hover. The image eases in 3.5% inside its frame, the brackets around the name open by 5px, the description and label go white. The brackets are already the signature of these titles, so the cue comes from the design, not from an added arrow.
  • Focus. Same feedback plus a 2px white ring 8px out, so keyboard users see exactly what hover shows (WCAG 2.4.7).
  • Pressed. The image settles back to 1%, a quick physical confirmation.
  • Touch. Hover only runs on devices that hover, so one tap opens the card.
  • Link targets. Mondai goes to the case study collection, /mondai. If the design system CS misses launch it points straight at the framework CS (H13). Haven goes to /haven; its state is in triage (C3). Same tab, plain links, no transition yet.
  • Reduced motion. Only the color change remains.
