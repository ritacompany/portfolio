# CS2 Falling behind: state list

Loop of 6.2 s. Frame 720 by 680. Times are when each state begins; review strips are taken around each.

- 0.00 s: empty page (loop seam: matches the last frame)
- 0.00 s to 0.35 s: labels and rows fade in. This week: row 1 open, rows 2 and 3 checked and dimmed, row 4 open. Next week: 3 rows.
- 0.70 s: row 4 gets its check, then dims
- 1.80 s: week ends. Row 1 is the only open one. It lifts, grows to 1.08, shadow comes up
- 2.00 s: row 1 travels straight down over rows 2 to 4
- 2.25 s: Next week's rows step down one place; its last row shrinks out
- 2.90 s: row 1 lands at the top of Next week, back to size, lighter border
- 3.05 s: This week closes the gap, top to bottom; Next week rises with it
- 3.70 s to 5.50 s: hold on the end state. This week 3 finished rows, Next week 3 rows with the carried one on top
- 5.50 s: labels and rows fade out
- 5.90 s to 6.20 s: empty page, back to the first frame

Labels and dividers fade with the rows at both ends, so the loop starts and ends on the empty page.
