# Spring sample state list

Loop of 4.6 s. Cuts are the moments a new state begins; review strips are taken around each.

- 0.00 s: angled, yaw -28, pitch 10, at rest
- 0.30 s: turn to face the viewer begins, lift begins
- 2.00 s: facing, settled
- 2.80 s: turn back to the angle begins
- 4.60 s: angled again, equal to the first frame (loop seam)
