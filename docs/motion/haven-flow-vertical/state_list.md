# States

1. Rest before play: 1 Identity quiz, 2 Review matches, 3 Select a Confidante (green), 4 Schedule a chat, 5 Intro chat.
2. Lift: Select at scale 1.06 on slot 3.
3. Travel: Select moving down to slot 5, Schedule a chat and Intro chat moving up one slot each.
4. Land: Select on slot 5 at scale 1, then a bump to 1.06 and back.
5. End (and reduced motion): 1 Identity quiz, 2 Review matches, 3 Schedule a chat, 4 Intro chat, 5 Select a Confidante.
