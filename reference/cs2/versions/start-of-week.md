## Version
Layout: T3I layout 6 (his)
Eyebrow: Start of week
Headline: Automatic could not mean silent, so the week opens on a recap that mirrors the screen people see when they finish a week early.
Text: Once leftovers moved into the next week on their own, the week needed a moment that showed it. Left silent, people would open a week that had changed without them. Asking them to choose what to take on, on the morning they were behind, read like paying to keep going.
Text: So each week opens on a recap of where the pace landed against the target and what the new week holds. Nothing on it asks for a decision.
Text: Pace only moves here. If it moved with every Action Item, people would watch it slip all week. Held to the start of the week, it changes once, and the screen says why.

Caption 1, Clean slate (his, kept): A clean slate only means something if no day was lost, so a week with a lost day goes to rollover.
Caption 2, Rollover: Leftovers carry the magenta rollover tag, which marks them as last week's work moving forward. Magenta was kept because it does not read as an error.
Caption 3, Catching up: Shows only when someone behind won back days last week. From behind, progress is easy to miss, so the screen names it. A week that only kept pace does not count.
Caption 4, Caught up: Shows the week the pace reaches the target again. It tells someone the catching up is over.
Caption 5, Recalibration: After several short weeks, the plan looks at what someone has done and suggests fewer weekly hours. While behind, it can only suggest fewer. Skipping it is allowed, with a warning.
Caption 6, Reset: After a long absence, the week rebuilds from today and the progress already made is kept. There is one button, Start from today. A keep my plan option would win by default, even when it is the plan they can no longer catch up to.
