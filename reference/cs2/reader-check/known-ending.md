The ending follows Start of week.

K1. Mondai is an AI career tool that builds a personalized route into tech meant to fit busy lives. The author designed the framework that connects it.
K2. The route is the Growth Journey: five Pathways, each split into Focus Areas and Action Items.
K3. The Growth Journey page holds the whole route with a journey target, pace and progress. Example: journey target June 12, 2027. It is kept out of the weekly screens on purpose.
K4. The Pathway page shows one Pathway's Focus Areas and Action Items in order.
K5. The Action Hub is this week's list of Action Items, opened nearly every day. Only the Active item at the top can be checked off.
K6. The Pathway target is the date the Pathway should be done by, set from the hours the person gives each week. The pace is where progress says they will finish; it updates once a week. The gap in days is the only ahead or behind signal. There is no streak.
K7. The Action Item page is plain containers the AI fills with text.
K8. Calendar sync is optional. Mondai only reads the calendar, never writes Action Items into it, and never moves a scheduled time on its own. People can move times themselves.
K9. Capacity is the hours a user says they can give each week, set by the user. With cognitive load, the effort each Action Item takes, it sets how many Action Items land in a week. Example: 6 hours a week can mean 3 Action Items one week and 4 the next.
K10. Buffer flow: finish the week early and next week's Action Items can be pulled forward to get ahead or catch up.
K11. Falling behind: anything unfinished on Saturday night rolls over into the next week on its own (rollover), and that week takes fewer new Action Items so it still fits the hours given.
K12. Start of week: the first screen each week, a recap and plan that changes with what the person needs. Templates: Clean slate, Catching up, Rollover (carried items under a magenta tag, so the plan never changes unseen), Recalibration, Reset.
K13. Recalibration: when short weeks keep happening, the screen says the user has been averaging around 6.3 hours against the 10 they set and recommends 6, showing what changes (example: journey target June 12, 2027 to January 10, 2028). They can take it, set their own or skip it with a warning.
K14. Reset: after a long absence (example: 24 days), the week rebuilds from today with progress kept and new target dates; it shows resume at Action Item 19 of 56. One button.
K15. The person in the screens is Aisha.
