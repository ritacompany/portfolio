# What the reader already knows, per version (round 5)

Built 8 Nov from reference/cs2/review-2026-11-07/final-copy.md with the round 3 proposals applied, page in order.
Each fact says which versions may count it as known. When judging a version, use only the facts marked for it.

K1 (known to V1 to V7). Mondai builds each user a curriculum for the tech career they choose, called their Growth Journey; it can take months. Most users don't have the same hours free every week, so the weekly framework turns the curriculum into weeks the user can finish, planned around the hours they can give. Mondai hasn't launched; the case study shows reasoning, not results.
K2 (V2 to V7). Mondai shows two dates side by side, a target date and a pace date, like CareerFoundry. A connected calendar suggests where work fits and the plan runs without one. Mondai's home screen shows only this week's work.
K3 (V2 to V7). The Growth Journey is five Pathways, one at a time in order; each holds Action Items, grouped into Focus Areas. The Growth Journey page holds the whole route, with the journey's own target, pace and progress. Each Pathway has its own page.
K4 (V2 to V7). The Action Hub is the screen of this week's Action Items, finished in order; only the top one, marked Active, can be checked off. The AI writes each Action Item.
K5 (V2 to V7). Capacity is the hours a user says they can give each week, set the first time they open the Action Hub; everything is planned from it. Effort is how much work each Action Item takes. Example user Aisha: capacity 6 hours, 4 Action Items last week, 3 this week.
K6 (V2 to V7). Calendar sync is optional; users who turn it on set a time range and their sharpest hours.
K7 (V3 to V7). With a calendar synced, the Action Hub can show the week as a schedule; times are suggestions; an Action Item is due by the end of its week, Saturday night.
K8 (V4 to V7). The right rail shows the Pathway target (set from capacity, holds steady through an ordinary week), the Pathway pace (where progress says they will finish, updates once a week) and the gap in days.
K9 (V5 to V7). Rollover: an Action Item still open on Saturday night moves into the next week on its own, takes up some of that week's capacity and pushes the pace later; the target stays.
K10 (V6 and V7). Buffer flow: finishing the week early offers next week's Action Items to pull forward.
K11 (V7). Start of week: the first screen each Sunday, in five versions; Recalibration suggests a lower capacity when Rollover keeps happening.
