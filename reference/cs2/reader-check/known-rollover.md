# What the reader already knows before the rollover block

Fixed list for the reader check. Change it only when an earlier block's approved copy changes.

K1. Each week has one deadline, Saturday night.
K2. Each week is sized to the hours a person says they can give each week (capacity). Each Action Item has a cognitive load, so a week with heavier items holds fewer of them (the personalized timeline example: capacity of 6 hours, 3 Action Items one week and 4 the week before).
K3. The Action Hub is the screen people open most. It lists this week's Action Items, each a piece of work shown as a card (the Action Hub list).
K4. A Pathway target and a Pathway pace show how the current Pathway is going.
K5. Scheduled times: a person can move any Action Item to a new time; a passed time drops off the card and the item stays open for the rest of the week.
K6. Calendar sync connects a person's own calendar to Mondai and unlocks the schedule view, where this week's Action Items sit between their events. Preferred hours and focus hours guide where Action Items go first.
K7. A reschedule icon on each card opens a way to pick a new time.

Not yet shown: what happens to Action Items still unfinished when the week ends, the screen that opens a new week, recalibration and reset.
