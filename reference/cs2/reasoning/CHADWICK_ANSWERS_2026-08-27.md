## Note on the Reset undo

Context for the question, since it was not clear. Reset auto-applies the schedule update rather than
asking. During that argument a middle path was proposed: apply it automatically but pair it with a
prominent, reversible action, along the lines of "your journey was updated to start from today, want it
back the way it was", the Gmail undo-send pattern [2026-05-23 deep-dive-into-week-flow-setup #0079].

The question is whether that undo was ever added. The sources do not say. If it was not, Reset applies
with no way back, which is a stronger position than the record shows and worth being sure about before
the case study describes it.
