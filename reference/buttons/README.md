# Button references

Two screen recordings Chadwick took on 17 Oct 2026 of paid Framer marketplace buttons he wants
to recreate for the portfolio, plus frame sheets so a session can read the motion without
playing the video. The free rebuilds are in `prototypes/homepage-foundations/liquid-buttons.html`
(web) and `liquid-buttons-framer.tsx` (Framer code components, untested in Framer).

| File | What it is |
| --- | --- |
| `gooey-liquid-button-recording.mov` | The grey pill. "Gooey Liquid Button" by Khanh Huu, $5. Label and icon merged at rest, pulled apart on hover. 6 s, 2850 x 1918. |
| `gooey-liquid-button-frames.png` | 36 crops of the button from that recording, 6 per second, read left to right then down. |
| `liquid-button-recording.mov` | The outlined pill. "Liquid Button" by Blue Jackson, $10. The outline bends toward and around the pointer and settles back; a cyan fill shows where the outline moved. 16 s, 2850 x 1918. |
| `liquid-button-frames.png` | 66 crops from that recording, 4 per second, same reading order. |

His asks, in his words from the 17 Oct chat: "I like the effect of how it reacts" (the outlined
one) but "I don't like that there's like that blue button hidden behind the liquid one", so the
rebuild has no fill. The grey one he likes as is.

Listings: https://www.framer.com/marketplace/components/gooey-liquid-button/ and
https://www.framer.com/marketplace/components/liquid-button/
