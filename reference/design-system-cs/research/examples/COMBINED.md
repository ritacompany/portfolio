# Every reference page in one table

25 Nov 2026. One table for every page judged against CS3 so far: the 18 pages from the first two passes, rechecked by an agent that read the CS3 outline, numbers and strategy first, and 33 new pages from the third pass, judged the same way. Ordered by how useful each is to CS3, passes and high relevance first. The experience rule applies throughout: stated years, a long list of systems or a senior body of work count, not only the word senior.

Pass means agents build from the system and it was changed so they could, plus strong on two of: an experienced designer wrote it, counted proof, small team honest about gaps. Every number is the author's own claim. Detail per page is in RELEVANCE.md (rows from the first two passes) and CLOSE-3-EXAMPLES.md (third pass). The earlier pass files are kept unchanged.

Flags: Klai and the krpadesigns repo pass on the rule but their authors are not shown to be designers, so use them for method only. Adam Hickey's page is a fictional product. Charles Sanderson passed the first pass and fails this recheck, because agents wrote his system but nobody measured agents building screens from it. Tarkowska's page appears in both the recheck and the third pass; it is listed once.
