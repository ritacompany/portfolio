# Step 5, setup A: two passes, message plan then layout

Pass 1, message plan. Write `message.md`. For each block of the copy file, in order:
- Claim: the block's headline as a claim.
- What the reader has to see to believe it: one sentence.
- Do the headline, body and Label lines, set as plain text, already make them see it? If yes, the block
  is text only and the labels stay as text. Stop there.
- If no: the one thing to show, and where it comes from (a real Mondai screen he will pick, or a new
  figure described in words). A second figure only if a named part of the claim is left unproven by both
  the first figure and the copy; write which part.
- Figure count, with the reason for each figure.
Do not name any layout piece in pass 1.

Pass 2, layout. Read only `message.md` and the layout decoder in LEDGER.md. For each block pick the
layout piece whose number of media slots equals that block's figure count. Write `section-1.md`: first
line `Section: 1`, then one table `| Layout piece | Slot | What goes in it | Why |`, a row per slot.
Every media row's Why names the part of the claim it proves.
