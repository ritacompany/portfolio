# Step 5, setup B: start as text, add only what the words cannot do

Every block starts as text only: eyebrow, headline, body, nothing else.
For each block, in order:
1. Read the eyebrow, headline and body as the reader would. Write the one thing the reader still would
   not believe, picture or remember from the words alone. If there is nothing, the block stays text
   only and that is the answer.
2. If there is something, describe the single figure that fixes exactly that gap, and nothing else.
   Label lines in the copy that the figure does not need fold back into the body or get cut; say which.
3. Ask again: with that figure, is anything still missing? Add a second figure only if yes, naming what.
4. Pick the smallest layout piece in the LEDGER.md decoder that holds what you ended with.
Write `section-1.md`: first line `Section: 1`, then for each block one line "Block N, without a figure
the reader misses: ..." and then one table `| Layout piece | Slot | What goes in it | Why |` with a row
per slot for the whole section.
