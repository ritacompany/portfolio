# Step 5, setup C: storyboard of headings and pictures

Write the section first as if the reader only ever sees eyebrows, headlines and figures, never body
text. For each block, in order:
1. Read the headline alone. Does it already land the point? If yes, no figure.
2. If not, describe the one picture that, under that headline, makes the point with no body text. Say
   what single thing it shows. If you need two pictures, say why one cannot do it.
3. Check the storyboard as a strip: read all headlines and pictures top to bottom. Neighbouring pictures
   change one thing. Cut any picture that repeats a point already landed.
Only then attach the body text from the copy file under each block, and pick the layout piece from the
LEDGER.md decoder whose media slots match the storyboard.
Write `section-1.md`: first line `Section: 1`, then the storyboard as a numbered list (headline, then
picture or "no picture"), then one table `| Layout piece | Slot | What goes in it | Why |` with a row
per slot.
