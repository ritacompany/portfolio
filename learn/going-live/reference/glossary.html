Glossary

Every lesson uses these words with these meanings. Grouped by the piece they belong to.

The address

Domain
The name people type, such as chadwickfenner.com. Rented a year at a time, never owned outright.
Registrar
The company you rent the domain from. Yours is Wix today and Porkbun after the move.
Transfer
Moving a domain from one registrar to another. The new one charges a year's rent and adds that year to the expiry date.
Transfer code
A one time password the old registrar emails you, proving you own the domain. Also called an auth or EPP code.
Transfer lock
A setting that blocks moves. Unlock it in Wix before the move. Separately, changing the owner's name or email adds a 60 day lock.
Auto renew
The registrar charges your card each year without asking. Turn it off at Wix when the move starts.
Grace period
About 30 days after expiry when you can still renew at the normal price.
Redemption
About 30 days after the grace period when recovery costs an extra fee. After it, the name is released to anyone.
Privacy
Hides your name and address from the public registry record. Free at Porkbun.

The connection

DNS
The lookup that tells a browser which computer answers for your domain.
DNS record
One line in that lookup. Pointing your domain at Vercel takes two of them.
Nameservers
The company that answers the DNS lookup for your domain. Usually the registrar.
DNSSEC
A tamper seal on DNS answers. It has to be switched off before a move or the address can stop resolving for a while. It is on for your domain today.

The building and what is inside

Hosting
The always on computer that hands your files to visitors. Yours will be Vercel.
Static site
A site made only of files, with no database or server code. Yours is one. The simplest and cheapest kind to host.
Repo
The GitHub folder holding the code and its full history: ritacompany/portfolio.
Branch
A separate copy of the code where a change is made without touching the live version.
Pull request
A request to merge a branch into the live version. Where you say yes or no.
Build
The step that turns the repo into the exact files that get served. Yours copies the site folder.
Deploy
Putting a build on the host. Vercel does it by itself on every save.
Preview link
A private web address Vercel makes for each branch, so you can see a change before it is live.
Production
The live version, the one at chadwickfenner.com.
Rollback
Putting the previous live version back in one click.
Noindex
A rule asking search engines not to list the site. On until launch.
