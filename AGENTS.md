# Portfolio

Read `CLAUDE.md` in this same directory first. It carries the full working instructions for
this project: whose portfolio this is, how to work with Chadwick, what is in the folder, the
evidence rules and who approves. It is kept in one place on purpose so it does not drift
between tools.

Then read, in this order:

1. `docs/PROJECT_CONTEXT.md` : purpose, the Figma source of truth, current work, guardrails
2. `docs/ABOUT.md` : approved biography. Empty until facts are approved
3. `docs/VOICE.md` : approved writing guidance. Empty until distilled
4. `docs/DECISIONS.md` : durable choices and why
5. `NEXT.md` : the current short list
6. `LEDGER.md` : state of the case study layout rebuilds in `build/`

The standing rules in `.claude/portfolio-rules.md` are injected automatically in Claude Code
but not in other tools, so read that file too.

Record durable decisions in `docs/DECISIONS.md` and update `NEXT.md` when the immediate
priority changes. Do not invent biography, project facts, outcomes, research findings or
metrics.
