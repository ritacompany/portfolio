# Speak ideas once, let Claude sort them

Pick **Voicenotes Pro** as the app path and start there. It records on iPhone and Apple Watch, transcribes and sits in Claude's official connector directory with a connector that can **search, read and write** your notes. Once it is connected, you can say "pull together everything I've said about X this month" in any Claude chat, including on your phone ([Voicenotes help](https://help.voicenotes.com/en/articles/14336494-voicenotes-mcp)). The DIY path is a Shortcut on the Action Button that records, transcribes on the phone and drops a plain text file into an iCloud folder. A **Claude Code Desktop scheduled task** then cleans, tags, links and digests those files every morning ([Desktop scheduled tasks docs](https://code.claude.com/docs/en/desktop-scheduled-tasks)). Go with Voicenotes now: setup takes minutes, there is nothing to maintain and it covers the shower through the Watch app. Build the DIY version only if owning plain files on your Mac matters more to you than zero upkeep, or if Voicenotes' search turns out weak on a large history (nobody has tested that independently). For the Apple Notes backlog, export everything once with the free **Exporter** app, which keeps dates and folders. Then point Claude Code at that folder and have it build an index, themes, duplicates and a short list of ideas worth pursuing, without deleting anything ([App Store](https://apps.apple.com/us/app/exporter/id1099120373)). What stops a new pile from forming is a weekly review, not the app.

## Voicenotes wins because Claude can search it and write back to it

Several apps record a ramble and tidy it up. Only three have an official link to Claude, and they don't give Claude the same powers. **Voicenotes** gives Claude four tools: meaning-based search across your notes, a list by date or tag, the full transcript and the ability to create a new note with tags. Setup is one sign-in from Claude's connector directory, with no API keys. Once it is linked on the web or desktop, it also works in the Claude mobile app ([Voicenotes help](https://help.voicenotes.com/en/articles/14336494-voicenotes-mcp)). That write ability matters. You can ask Claude to file its synthesis back into Voicenotes as a note, so the summary lives next to the raw ideas instead of disappearing into chat history. **AudioPen** is the best at turning a ramble into clean prose, with adjustable rewrite strength, but Claude can only read it, and only on the paid Prime tier ([AudioPen](https://audiopen.ai)). **Letterly** has a hosted connector that can search, rewrite and create notes, and it allows 90 minute recordings ([Letterly](https://letterly.app/mcp); [App Store](https://apps.apple.com/us/app/letterly-ai-note-taker/id6464049772)). It's a solid backup if Voicenotes doesn't click.

| | Voicenotes | AudioPen | Letterly | Apple Notes |
|-|-|-|-|-|
| Claude access | Official, search and write | Official, read only | Official, search and create | No official phone path |
| Apple Watch | Yes | Yes | Yes | Built in recording |
| Recording cap on paid tier | Not stated | 15 minutes | 90 minutes | Not stated |
| Paid tier | Pro, $9 a month on its site | $99 a year | Not verified | Free |
| Privacy claim | Never used for training | Audio deleted within 48 hours | Not verified | On device |

Voicenotes' own pricing page lists Pro at **$9 per user per month**, and the Claude connector is a Pro feature ([Voicenotes pricing](https://voicenotes.com/pricing)). A competitor quotes about $14.99, so the $9 is probably the annual billing rate ([Yaps](https://www.yaps.ai/pt-br/blog/voicenotes-alternative)). Voicenotes says recordings are never used to train AI and that it holds SOC 2 certification ([Voicenotes](https://voicenotes.com)). There is one real weakness: a competitor reports that a recording can be lost if the cloud upload fails, because nothing is stored on the phone ([Yaps](https://www.yaps.ai/pt-br/blog/voicenotes-alternative)). That source has a motive, so treat it as a warning to check, not a fact. One more caveat applies to every app here. None of them automatically links a new memo to related old ones. The "this connects to what you said in March" moment happens when you ask Claude, not when you record. So the connector matters more than the app's own tagging.

For the shower, the Apple Watch is the hands-wet route. Voicenotes, AudioPen and Letterly all have Watch apps ([Voicenotes](https://voicenotes.com); [AudioPen](https://audiopen.ai)). No vendor documents Action Button or Siri support. Any app that offers a Shortcut can usually be put on the Action Button, but test that before you rely on it. Check two things on day one: whether the Watch app records without the phone nearby, and whether it syncs later.

## The DIY build keeps the phone dumb and does the thinking on your Mac

The DIY version follows one rule: **the phone only records and saves, and all AI work happens later on the Mac.** That way a failed AI step never costs you an idea. Pressing the Action Button runs a Shortcut. It records, transcribes on the device with Apple's Transcribe Audio action and saves a timestamped text file, plus the audio, into an Inbox folder in iCloud Drive. Apple describes that action as on device ([Spokenly](https://spokenly.app/blog/voice-memo-to-text-iphone)). On the Mac, a Claude Code Desktop scheduled task runs daily. It reads every new file in Inbox, cleans up the transcript, adds tags, links each idea to earlier related ones, moves it into an Ideas folder and appends to a weekly digest. These tasks run only while Claude Desktop is open and the Mac is awake. If a run is missed, one catch-up run happens on wake for anything missed in the last seven days, so ideas get delayed, never skipped ([Desktop scheduled tasks docs](https://code.claude.com/docs/en/desktop-scheduled-tasks)). Everything runs on your existing Claude plan with no extra API bill. The folder is plain Markdown, so Obsidian can open it as a vault if you ever want a nicer reading view ([MindStudio guide](https://www.mindstudio.ai/blog/build-ai-second-brain-claude-code-obsidian)).

Plan on one to two hours of setup. The likely break point is iOS itself. After iOS 26 shipped, users reported that Shortcuts using the transcription action failed with an audio error, and it was unclear whether later updates fixed it ([Apple Community](https://discussions.apple.com/thread/256155805)). Third party actions such as Shortcut Recorder's on-device transcription work as a fallback ([App Store](https://apps.apple.com/app/id6760636603)). Saving the audio file next to each note means a bad transcription can be redone. Two other fail points: iCloud can sync slowly, so a note recorded at 6:58 may miss a 7am run (it gets picked up the next day), and a task can stall waiting for a permission prompt until you approve it once with "always allow" ([Desktop scheduled tasks docs](https://code.claude.com/docs/en/desktop-scheduled-tasks)).

There is also a zero-build option: use the **Claude app itself as the inbox**. Put Claude on the Action Button or Lock Screen, open a Project called "Idea inbox" and dictate into it ([Claude support](https://support.claude.com/en/articles/10302511-accessing-claude-app-on-ios-lock-screen-control-center-and-action-button); [Claude support](https://support.claude.com/en/articles/10065434-use-dictation-on-claude-mobile)). Each Project keeps its own memory, and paid plans can search past chats, so later chats in that Project can pull ideas together ([Claude support](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context)). The catch is that ideas live as chat history, not as notes you can browse, export or use with anything else. That's fine for a week-long trial and a poor long-term archive. Skip the Zapier, Make and n8n chains. They need paid plans and separate API keys, and they break across several services ([We Eat Robots](https://weeatrobots.substack.com/p/voice-memo-ai-automation-productivity-workflow)).

## The backlog: export once, then let Claude build a map

Don't give Claude live read-write access to Apple Notes for the cleanup. Work from an export, so nothing can be edited or deleted by accident. Do it in four steps.

**First, prepare the notes.** Unlock any locked notes you want included, since most tools skip them ([Obsidian Help](https://obsidian.md/help/import/apple-notes)). For notes that hold audio recordings, use the recording's menu to add the transcript into the note body. Otherwise the audio exports as a sound file Claude can't read ([9to5Mac](https://9to5mac.com/2024/08/01/audio-transcription-in-ios-18-how-to/)). Let iCloud finish syncing on the Mac so iPhone-only notes come along.

**Second, export with Exporter.** It's a free Mac App Store app that writes Markdown, keeps creation and modification dates, mirrors your Notes folders and includes attachments. It was updated for macOS 26 ([App Store](https://apps.apple.com/us/app/exporter/id1099120373)). Use Obsidian's Importer instead only if you've already decided Obsidian is the long-term home. Be aware that one reviewer saw 36 of 400+ notes fail with no clear reason ([MacStories](https://www.macstories.net/stories/obsidians-importer-plugin-lets-you-move-your-apple-notes-to-any-note-taking-app-that-supports-markdown/)). Avoid the well-known sirmews Apple Notes server, which is read-only, needs Full Disk Access and was archived in August 2025 ([GitHub](https://github.com/sirmews/apple-notes-mcp)).

**Third, have Claude Code build a map, not a cleanup.** Open the export folder in Claude Code and ask for six things in a new folder. One is an index with a row per note giving its date, folder, a one-line gist and a type (idea, task, reference, journal or junk). Next come theme clusters, each with links to its notes, its date span and a short summary of what the cluster keeps circling. Then come duplicate groups merged under one clear statement with every source kept, and a ranked list of the 10 to 20 most promising ideas, each with a next step. Tasks go in their own list. Last is a list of archive candidates for you to approve. This structure follows research showing that grouping short notes by meaning, then having a language model name and merge the groups, beats older keyword methods on short, messy text ([arXiv 2509.19365](https://arxiv.org/html/2509.19365v1)). Check the theme names yourself, because automatic labels drift ([Jeff Bullas forum](https://www.jeffbullas.com/thread/topic-modeling-vs-llm-clustering-for-text-whats-the-difference-and-when-to-use-each/)). Pay attention to the date span. An idea you've come back to over three years is a stronger signal than one loud week.

**Fourth, move the winners forward.** Paste or have Claude create the top ideas in your new home: Voicenotes through the connector, or the Ideas folder in the DIY setup. Leave the rest in the archive. Nothing gets deleted until you've read the archive list.

One shortcut is worth checking. A July 2026 blog post describes a free Claude Desktop extension called "Read and Write Apple Notes" under Settings > Extensions. Per that post, it can search notes by meaning and append to them ([iProductivity](https://iproductivity.substack.com/p/apple-notes-finally-got-smart-with)). Anthropic's own docs don't confirm it, and a commenter reported line breaks collapsing when Claude wrote notes. If it shows up in your Extensions list, it's useful for small ongoing lookups, not for the big cleanup.

## Why this works for how your brain makes ideas

The shower ideas are real. A review of 117 studies found that stepping away from a problem modestly improves idea generation, and the effect is strongest for open-ended "come up with ideas" problems. It also grows after a solid stretch of work on the problem and when the break is an easy activity rather than a demanding one ([Sio and Ormerod 2009](https://www.Gwern.net/doc/psychology/writing/2009-sio.pdf)). Those ideas fade fast, so being able to record in one tap matters more than any feature list. Andy Matuschak explains the pile: most people use notes as a bucket for scratch thoughts and end up after a year with a heap of disconnected notes ([Matuschak](https://notes.andymatuschak.org/zNQV445UEcyLXVsRVgoVSfv)). His fix is one inbox kept apart from developed notes and emptied on a reliable rhythm. Inboxes only work when you trust how they get emptied ([Matuschak](https://notes.andymatuschak.org/§Inboxes_and_attention_management)). The Masicampo and Baumeister research on unfinished goals adds a useful habit. Writing a concrete plan, not finishing the task, is what stops an open thought from nagging you ([Psychology Today](https://www.psychologytoday.com/us/blog/tech-support/201310/why-your-to-do-list-drives-you-crazy)). In practice, end a voice note with "next step is..." when you can.

## Conclusion

The app and the automation are the easy part. Apple Notes failed you because it was a place to put ideas with nothing that ever brought them back. Either path fixes that only if you give Claude a standing job: a weekly pass that says what's new, what connects to older ideas and what deserves a next step. Voicenotes makes that a single chat prompt, and the DIY build makes it a scheduled task. Set up the weekly review the same day you install the app.

The backlog is worth more than it looks. Years of scattered notes are the best evidence you have of which ideas keep coming back, and a clustering pass with date spans shows exactly that. Do the backlog export first, before you start capturing new ideas. The themes it surfaces become the tags and Projects your new system files into, so the new inbox starts organized instead of becoming the next pile.
